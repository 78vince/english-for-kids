Game Design Tokens

遊戲專用視覺規範：柔和色系、圓潤造型、扁平 icon、可彎曲肢體的人物（正／側／背）、森林場景（日／夜）。內容與英語無關，目的在帶來學習動機與樂趣。來源 game-tokens.json，所有圖形由程式依 token 繪製。

        4. 角色 × 場景

        肢體分兩段、關節圓滑彎曲；可切換正面、側面、背面。用下方虛擬按鍵試玩：←→ 走、按住 B 加速奔跑、↓ 蹲、A 跳；也可以用實體鍵盤：方向鍵移動；A 鍵、Space、J＝A（跳）；B 鍵、Shift、K＝B（按住加速奔跑）。

        圖層

        預設角色 × 三視角

        5. 基礎動作（可彎曲肢體）

        上排側面、下排正面；膝蓋與手肘依 swing / spread / bend 三組參數彎曲。

        動作連播（序列）

        序列用 GameArt.sequenceAt(name, ms) 取樣，回傳該時刻的 pose／view／facing；播放端依回傳值重畫角色。「轉圈展示」用來呈現三視角，「打招呼」播一次後停住。

        6. 森林場景（遠・中・近景＋日夜）

        圖層由後到前：天空 → 星星 → 雲 → 遠景 → 中景 → 地面 → 近景 → 樹冠前景；每層可無縫水平平鋪，視差速度見 token。太陽與月亮是獨立物件（見道具），可沿弧線日升月落。

        日夜色票

        6b. 攝影棚場景

        只有「天空漸層・散景・地板」三層，專拍人物；日／夜只改變燈光色調，沒有太陽與月亮。用上方的「場景」切換即可在舞台試用。

        7. 道具與物件

        滑鼠移到道具上可放大並列出所有狀態；有綠點的道具可互動，點擊切換狀態。

        8. 頭像與拍照匯出

        頭像：GameArt.avatar(look, size) 裁出頭部，供個人檔案與各關卡右上角使用。拍照：GameArt.exportSVG(opts) 輸出獨立 SVG（CSS 變數與夜晚濾鏡已展開），GameArt.exportPNG(opts) 轉成 PNG；尺寸 16:9＝1920×1080、1:1＝1080×1080、4:5＝1080×1350。到上方「角色 × 場景」按「拍照」即可試。

        9. 賽跑（對手動物・裁判・賽道）

        對手：GameArt.animal(kind,{pose,t,facing})／GameArt.animateAnimal(svg,pose)（烏龜・兔子・鴕鳥；姿勢 idle／run／sleep／stumble／cheer／sad，動畫啟動時同步套 t=0，不會閃殘影）。裁判＝角色系統的 bear。賽跑道具見上方「道具」（群組：賽跑）。數值與賽道資料在 race，平衡試算：node race-sim.js。

        熊熊裁判

        賽道（第 1–3 場；依 stage.items 排列，x 為賽道單位 0–3600）

        10. 爬樹（高度分層背景・樹枝・障礙／道具）

        資料：treeClimb（世界 50 單位＝1 m、頂高 160 m；3 難度 120/90/60 s）。API：GameArt.treeBuild(levelId,seed)、treeCompose(camAlt,w,h,{branches,sprites})、treeChunk、treeSkyAt。試算：node tree-sim.js。滑桿＝鏡頭高度（m）。
