# 交接：爬樹「彈跳蕈」做成真正的彈跳（App 端）

> 內容端不用改 token：素材、數值、地形都已經有。這份只要 App 端把行為做對。先處理上一份驗收回報的「樹枝畫面元素用 `b.id` 當 key 會重複」（改用 `b.uid`），否則蕈也會跟著看不到。

## 現況（token v2.0.0，已存在）
- 地形資料：`treeBuild` 回傳的樹枝有 `shroom: true` 者，蕈長在該樹枝中央。每局平均 小樹苗 6.8／大橡樹 7.6／千年神木 2.6 根。
- 素材：`GameArt.prop('springShroom', { state: 'idle' | 'squash' })`，尺寸 64×52，碰撞框 `[4,12,56,40]`（`collider.effect = 'shroom'`）。
- 數值：`effects.shroom.mult = 1.5`（跳高倍率）。

## 要做的行為
1. **落上去就彈，不需要按 A。** 角色往下落（`vy ≤ 0`）、腳踩到蕈傘頂（水平落在蕈的碰撞框內即可，不是整根樹枝）時，自動以 `v0 × √mult` 起跳（跳高 130×1.5＝195，與一般起跳同一個重力）。
2. **蕈只在蕈的範圍有效。** 站在同一根樹枝上蕈以外的地方，仍是普通落地。走上蕈傘（不是落下）也不觸發。
3. **↓ 不觸發。** 按住 ↓ 時（穿越下跳期間）不彈，照一般穿越處理。
4. **畫面回饋：** 彈起瞬間切 `springShroom` 的 `squash` 狀態約 120 ms，再回 `idle`；角色用 `jump` 姿勢。提供輕微彈起音效或震動即可（可略）。
5. **彈跳中的控制：** 與一般空中相同（空中水平控制 0.8、可左右微調）；不要因為彈高而讓鏡頭倒退（鏡頭仍只往上）。
6. **現有「在蕈樹枝上按 A 才加成」的寫法請移除**，統一用上面第 1 點，避免兩套規則。
7. **一般樹枝的跳躍不變。** 沒有蓄力、沒有新按鍵。

## 驗收
- 在 sapling 開幾局：蕈看得見（`uid` 修好後），落上去自動彈高，高度約為一般跳的 1.5 倍。
- 走過蕈、站在蕈旁、按 ↓ 下跳穿過蕈所在樹枝，都不會誤彈。
- 彈起時不被脆枝、單向平台卡住；落下時仍可踩到上方樹枝。
- `verify-tree-climb` 新增一條：模擬角色落在 `shroom` 樹枝蕈範圍內，起跳速度 ≈ `v0×√1.5`。

## 備註
- 模擬器目前只把蕈當成「成功率 +4%」，沒有算 1.5 倍高度的省時效果；實機後若蕈太強或太弱，回報體感，內容端再調 `effects.shroom.mult` 或每局蕈數。
