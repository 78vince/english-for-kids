# 企劃：第一關「人物設定」（角色工作室 Character Studio）

*撰寫：2026-10-08（內容端）｜適用專案：English for Kids LetsGo（App 端實作）｜視覺與資料規範來源：`assets/game-tokens/`（v0.3.x）*
*狀態：企劃定案（§13 全採建議）。下一步：M1 內容端補 token，再拆 handoff。*

---

## 1. 一句話與目標

**讓孩子在一個安靜、好玩的小空間裡，把「自己的角色」打扮成喜歡的樣子，存起來，帶著它走、跑、跳、做表情動作，換不同場景，最後拍一張屬於自己的照片。**

| 目標 | 說明 | 成功指標 |
|---|---|---|
| 擁有感 | 角色是「我的」，之後所有關卡都用它當主角 | 完成首次儲存的使用者比例 |
| 動機 | 與英語內容無關，單純好玩，作為學習獎勵的出口 | 一週內回訪工作室次數 |
| 熟悉操作 | 這關同時是「新手教學」：虛擬按鍵 ↑↓←→ A B 的所有用法都在這裡學會 | 首次進入 60 秒內完成走、跳、蹲 |
| 創作與分享 | 拍照功能產出可保存、可分享的成品 | 每位使用者累計照片數 |

非目標（這一關不做）：關卡通關計分、敵人、時間壓力、需要閱讀長文字的任務、與英語題目的強制連結。

---

## 2. 使用者與情境

- **主要使用者**：正在上 Level 4 課程的孩子（約小學中年級），平板為主、手機為輔，偶爾用電腦鍵盤。
- **情境**：寫完一輪複習後，想「獎勵自己」；或家長允許的自由時間。區網內多台設備使用同一帳號，角色與照片要跟著帳號走。
- **設計原則**：一眼看懂、不需讀字也能操作（icon 為主）、不會誤刪（有確認與復原）、永遠可以回上一步、離開前自動存檔。

## 3. 整體流程

```
遊戲室 / 首頁入口「我的角色」
        │ 全螢幕整頁（不用 iframe）
        ▼
 ┌──────────────── 角色工作室 ────────────────┐
 │  造型 ─ 動作 ─ 場景 ─ 相機   （右側分頁）     │
 │      ↓                                       │
 │  即時預覽（舞台）＋ 虛擬按鍵試玩               │
 │      ↓                                       │
 │  儲存（自動＋手動）→ 角色槽 1/2/3             │
 └──────────────────────────────────────────────┘
        │ 拍照 → 預覽 → 存相簿 / 下載
        ▼
 離開：自動存檔 → 回遊戲室；其他關卡載入「目前使用中的角色」
```

首次進入有 3 步輕量導覽（點選造型 → 按 A 跳 → 按相機），可略過，只出現一次。

## 4. 畫面規劃（橫放全螢幕，≥ 820×480）

```
┌────────────────────────────────────────────────────────────┐
│ ← 返回      角色名稱 ✎        [撤銷][重做]   💾已存    📷 │ 頂部列
├───────────────────────────────────────┬────────────────────┤
│                                       │ ［造型］動作 場景 相簿│
│                                       │ ┌────────────────┐ │
│          舞台（森林・白天）             │ │ 分類：身體/頭髮/ │ │
│            ｜ 角色 ｜                  │ │ 臉/服裝/配件/手持│ │
│                                       │ │ 色票、款式縮圖   │ │
│  （只有舞台內的 HUD：代幣 / 時間）       │ └────────────────┘ │
├──────────────────────┬────────────────┴────────────────────┤
│  ↑ ← ↓ →  十字鍵      │          A（跳）  B（加速奔跑）       │ 虛擬按鍵
└──────────────────────┴─────────────────────────────────────┘
```

- **舞台**：約 62% 寬；右側面板約 38%（平板）。手機直放時面板改為底部抽屜，舞台縮小置頂；虛擬按鍵在舞台上緣兩側浮現，面板展開時自動隱藏按鍵。
- **面板分頁**
  1. **造型**：左側分類列（身體／頭髮／臉／服裝／配件／手持物），右側為款式縮圖格與色票列；點選立刻套用到舞台角色。底部固定「隨機」「還原」「預設角色」。
  2. **動作**：動作按鈕格（待機、揮手、歡呼、暈眩、蹲下⋯）＋「連續播放」；與虛擬按鍵獨立（按下動作鈕＝角色原地表演，再按或移動即結束）。
  3. **場景**：場景縮圖輪播（見 §8）＋時間控制（白天／夜晚／系統時間／拖曳時間）。
  4. **相簿**：照片縮圖、刪除、下載。
- **視角**：舞台右下「正面／側面／背面」切換鈕（編輯造型時預設正面，進入試玩移動時自動側面）。
- **icon 一律用 token 的扁平 icon**；文字樣式沿用 `.g-t-*`；所有可點擊區 ≥ 56px。

## 5. 功能規格

### 5.1 造型（資料皆來自 `character.options`，內容端維護）

| 類別 | 目前可選 | 本關建議補足（內容端先做，見 §11） |
|---|---|---|
| 物種 | 小孩、小熊 | 保留；之後可擴充（小兔等） |
| 膚色／毛色 | 6 種膚色；小熊 3 種毛色 | 毛色加 2 種 |
| 髮型 | short、bob、bun、puff、ponytail、none | +3 款（捲髮、雙馬尾、長直髮） |
| 髮色 | 8 色 | 維持 |
| 臉 | 眼 3 款、口 3 款 | 眼 +2（睫毛、閉眼笑）、口 +1（吐舌）、可選雀斑／腮紅色 |
| 服裝 | tee、hoodie、overalls、dress | +3（外套、條紋衫、洋裝款式 2） |
| 服裝／褲色 | 8＋5 色 | 維持；加上「花紋」（條紋、圓點）二期 |
| 配件（可複選） | 圓眼鏡、軟框眼鏡、帽子、蝴蝶結、耳機、領巾、圍巾、背包 | +4（星星髮夾、護目鏡、翅膀、披風） |
| 手持物 | 旗子、棒棒糖、魔法棒、書 | +2（風車、小花束） |

操作要求：
- 點選即套用、可**撤銷／重做**（至少 20 步）；「隨機」會保留名字與物種。
- **預設角色**：5 組現有 preset 作為起點（首次進入隨機給一個）。
- 色票用「圓形色塊」，已選以外框標示；款式用縮圖（程式即時繪製，不需圖檔）。
- 不允許產生「看不見的角色」：任何組合都必須通過渲染檢查（服裝與配件的 Z 順序規則已在 token 定義）。

### 5.2 角色名稱與存檔

- 名稱：1–12 字，中英文數字，無內容過濾需求但禁止空白與純符號；預設「小夥伴」之類的友善名稱。
- **3 個角色槽**／每位使用者；一個為「使用中」。切換槽時自動存檔當前編輯。
- 儲存時機：每次變更後 800ms debounce 自動存；離開、切槽、拍照前強制存；右上顯示「已存」狀態點（同步中／已同步／離線稍後同步）。
- **刪除／覆蓋**一律二次確認（圖示＋兩顆大按鈕，文字簡短）。

### 5.3 試玩與操作（兼作新手教學）

- 虛擬按鍵與實體鍵盤沿用 token 規範：十字鍵走（←→）、↓ 蹲（蹲下不能前進）、↑ 預留（未來爬梯）、A 跳、按住 B 加速奔跑；鍵盤 A/Space/J、B/Shift/K。
- 物理與手感沿用預覽頁已調好的參數：跳高約舞台高 26%、拋物線、落地 0.24 秒且移動中不中斷、跑跳比走跳遠（空中水平速度由起跳時是否按 B 決定）。
- **試玩小場域**（不計分、純好玩）：場景內擺幾個可互動物件——禮物方塊（A 跳頂會彈出彩帶）、彈簧、花苞（靠近開花）、寶箱（走近開啟）、營火（可滅可點）。互動狀態已在 token（`states`）。
- 「表演」：動作分頁的按鈕讓角色原地做出表情動作；可與背景音／音效配合（二期）。
- 輕量引導：頂部提示氣泡（例：「按 A 跳起來！」），完成一次就消失。

### 5.4 場景替換

見 §8，另需：切換時有 300ms 淡入淡出；角色位置保持在地面線；時間設定（白天／夜晚／系統時間）屬於「場景設定」，各場景獨立記憶。

### 5.5 拍照（截圖）

見 §9。

### 5.6 獎勵與連結（可選，建議納入）

- 首次儲存角色：+10 代幣；首次拍照：+5 代幣；之後不重複給（避免洗代幣）。
- 新徽章（沿用規則式徽章，交內容端出條件與圖案）：**造型師**（儲存 3 個不同角色）、**攝影師**（拍 1／10 張）、**環遊世界**（用過全部場景拍照）、**日夜都愛**（白天與夜晚各拍 1 張）。
- 個人檔案頭像改用角色頭像（取頭部裁切），讓孩子在全 App 都看到自己的角色。

## 6. 資料模型

```jsonc
// 每位使用者一份，key：levelUnitReview.character.v1.<profileId>（走區網伺服器同步）
{
  "version": 1,
  "activeSlot": 0,
  "slots": [
    {
      "id": "c1",
      "name": "小夥伴",
      "look": {                                  // 與 GameArt.character() 參數完全一致
        "species": "kid", "skin": "peach",
        "hairStyle": "short", "hairColor": "chestnut",
        "eyes": "dot", "mouth": "smile",
        "outfit": "hoodie", "outfitColor": "sky", "pantsColor": "stone",
        "accessories": ["glasses-round"], "held": "none"
      },
      "scene": { "id": "forest", "time": "day", "useSystemTime": false },
      "createdAt": 1790000000000, "updatedAt": 1790000000000
    }
  ],
  "stats": { "photos": 0, "scenesShot": ["forest:day"], "firstSaveRewarded": false, "firstPhotoRewarded": false }
}
```

- `look` 只存 id 字串，**不存圖**；未來 token 新增款式不需遷移；遇到未知 id 時以預設值替換（向前相容）。
- 同步沿用 server-sync 設計：以 key 為單位「較新者勝」，衝突舊值進 `conflicts/`；本機 localStorage 快取。
- 照片 metadata：`{id, slot, sceneId, time, aspect, createdAt}`；影像本體見 §9。

## 7. 角色與動作（內容端已完成／待補）

已完成（token v0.3.x）：兩段肢體、正／側／背三視角、10 種動作、自動貼地、蹲下腳掌與膝蓋、Z 順序規則、物件互動狀態。

本關需要內容端補的動作與表現：
1. **表情動作**：開心（happy 眼＋open 口）、驚訝、害羞、睡覺（閉眼、zZ）、思考（手托下巴）。
2. **姿勢**：坐下、敬禮、比 YA、轉圈（正面→側面→背面連續轉身，可用來展示三視角）。
3. **動作連播**：序列（例：揮手→轉圈→歡呼）以 JSON 描述，工作室「表演」可播放。
4. 所有新動作須通過「貼地、不穿幫、Z 順序」檢查（沿用現有測試圖）。

場景規範（已在 token）：圖層 `sky→stars→clouds→far→mid→ground→near→canopy`、可無縫平鋪、視差速度、日夜雙套色票、`skyAt(u)` 時間軸。**新增場景＝新增 token 色票＋圖層函式**，不需要改 App 邏輯；App 以 `GameArt.scenes` 與 `sceneInfo` 動態生成縮圖輪播。

縮圖：預先繪成小 SVG（即時繪製，不需圖檔）。

## 9. 拍照（截圖）規格

**技術路線（推薦）**：整個舞台都是 SVG，拍照時把「場景各圖層（含目前視差位移）＋太陽月亮＋角色＋道具」組成一個 SVG，轉成 Canvas 再輸出 PNG——不依賴 html2canvas，不需截螢幕，畫質不受裝置解析度限制。

- 注意點：CSS 變數（如太陽的 `--sunc`）與 `filter`（夜晚角色亮度）要在匯出時展開成實值；字型不內嵌（照片不含文字，除非加相框標題）。
- **構圖**：預設 16:9（1920×1080）；可選 1:1（1080×1080，聚焦角色）、4:5。取景框在舞台上顯示。
- **流程**：按相機 → 3-2-1 倒數（可跳過）→ 角色定格當前動作 → 快門白閃＋「喀嚓」音效 → 預覽彈窗（再拍／儲存／下載／刪除）。
- **相框與貼紙（二期）**：幾種圓角相框、日期戳記、簡單貼紙（星星、愛心、對話框）；貼紙為 token icon。
- **儲存**：
  - 一期：IndexedDB（本機）＋「下載到裝置」（`<a download>`）。
  - 二期：區網伺服器 `learning-data/photos/<profileId>/`，新增 `POST/GET/DELETE /api/photos`；縮圖 + 原圖；上限（例如 50 張／人）超過需刪除舊的。
- **分享**：區網 http 下 Web Share API 可能不可用 → 以「下載」為主；有支援的裝置顯示分享鈕。
- **隱私與安全**：照片全為卡通合成，不含相機畫面、不含個資；不上網，僅存在這台電腦與本機。
- 相簿：縮圖格、點開大圖、刪除（確認）、設為「目前角色封面」。

## 10. 技術架構（給 App 端）

- **頁面**：`games/character-studio.html`，同視窗導航、全螢幕、PWA standalone 友善（沿用「全螢幕遊戲」handoff：離開前 flush 同步、返回再 hydrate）。
- **共用層（之後所有遊戲重用）**：
  1. `game-tokens`／`game-art`（角色、場景、道具、icon）— 目前為經典 script，App 端轉成 ES module 並加型別（內容端維護 json 與算法，App 端不改圖形邏輯）。
  2. `VirtualPad` 元件（十字鍵＋A/B＋鍵盤對應＋多點觸控＋視窗失焦自動放開）。
  3. `StageController`：圖層 DOM、視差、日夜、角色位置與貼地、跳躍物理（參數見預覽頁）。
  4. `characterStore`：讀寫、debounce 自動存、同步狀態。
- **效能**：舞台以 rAF 驅動；圖層為 SVG 靜態、只做 `translateX`；角色姿勢每幀只更新 transform 屬性；`prefers-reduced-motion` 時停用視差與特效。目標 60fps（iPad 6 代以後）。
- **無障礙**：按鈕有 aria-label；色票除了顏色還有名稱（長按顯示）；對比 ≥ 4.5:1（token 已檢查）。
- **離線**：全部資源為本地；無外部字型請求（內嵌 Nunito＋Noto Sans TC 子集）。
- **測試**：各視角×各動作的快照圖（內容端已有腳本）；Playwright 流程測試（造型→儲存→重新整理→仍在→拍照→相簿）；雙裝置同步測試。

## 13. 決策（2026-10-08 使用者確認：採用全部建議，狀態＝定案）

| # | 問題 | 選項 | 建議 |

| 1 | 角色槽數量 | 1／3／5 | **3**：夠用且介面簡單 |

## 14. 驗收清單（第一關完成定義）

- [ ] 平板橫放 820×480 與 1024×768、手機橫放 640×360 皆可用，無元素被遮擋。
- [ ] 任意造型組合都不會出現穿幫（Z 順序、貼地、背包與耳機等配件）。
- [ ] 虛擬按鍵與實體鍵盤手感與預覽頁一致：蹲下不能前進、跳高、跑跳較遠、落地不中斷移動。
- [ ] 自動存檔：重新整理、換裝置、離線再上線後角色仍在；衝突有備份。
- [ ] 場景至少 3 個（森林、攝影棚、海灘），日夜皆可，時間可拖曳或用系統時間。
- [ ] 拍照：三種比例輸出、夜晚與太陽顏色正確、相簿可刪除與下載。
- [ ] 全程無外部網路請求；`prefers-reduced-motion` 有對應；對比符合規範。
- [ ] 獎勵與徽章只發一次；頭像正確顯示。
- [ ] 全專案 grep：無教材書名／出版社名。

## 15. 風險與對策

| 風險 | 影響 | 對策 |
|---|---|---|
| SVG 組合過多造成低階平板掉幀 | 手感差 | 圖層靜態、僅 transform；必要時降低樹木數量或關閉近景視差 |
| 匯出 PNG 時 CSS 變數／filter 未展開 | 照片與畫面不一致 | `exportSVG` 內明確展開；用快照圖比對 |
| 造型選項過多造成選擇困難 | 孩子卡關 | 預設分類收合、「隨機」與預設角色當捷徑；常用款置頂 |
| 照片累積占空間 | 伺服器磁碟 | 上限＋縮圖＋提醒；納入每日備份策略 |
| 區網 http 無 Web Share／crypto | 分享受限 | 以下載為主；不依賴這些 API |
| 內容端與 App 端 token 版本不同步 | 款式缺漏 | token 帶 `version`；App 啟動時比對並在開發模式告警 |
