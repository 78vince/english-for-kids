## 2. 圓石：碰到會跌倒
- 在測試場景地面放數顆 `rock`（建議 3–4 顆，間距不等，離出生點 ≥ 1 個畫面寬的 25%，避免一開場就撞到）。
- 碰撞盒＝道具 `collider.box`（`GameTokens.props.list` 的 `rock.collider`：`kind:'hazard'`，box `[10,12,44,28]`，道具座標），換算成舞台 px。角色碰撞盒（腳底往上）：寬約 36 單位、高約 120 單位，置中。
- **判定**：角色水平移動時，角色盒與 hazard box 重疊，且角色腳底**低於 box 上緣 4 單位以上**→ 絆倒；若跳起且腳底高於 box 上緣→安全跳過（落地踩在石頭上不算絆倒，直接滑落到石頭旁，或視為站上；建議：腳底高於上緣落下時當作 solid 站上去，不絆倒）。
- **絆倒流程**：播放序列 `GameArt.sequenceAt('trip', ms)`（絆倒 380ms → 趴倒暈眩約 1000ms → 爬起 520ms，共約 1.9 秒；**`view`／`facing` 沿用目前角色，不要採用序列裡的值**；pose 取序列回傳的 `pose`）。期間輸入全部忽略（含按鍵放開事件仍要處理，避免卡鍵）；跌倒時往前（面向方向）滑出少量距離（約 0.5 個角色寬），之後回到待機。冷卻：爬起後 600ms 內不再被同一顆石頭絆倒。
- 絆倒瞬間：浮出一次 `.g-float`（例如「哎呀」不需要，可用 `sparkle` 或星星 icon）、輕微畫面震動 ≤ 4px 120ms（`prefers-reduced-motion` 關閉）。
- 跌倒期間角色在地面，高度由動作本身（`root.y/rot`）決定，**不要再手動修正 y**。

## 3. 可踩踏：石頭方塊、木頭（含樹墩、草地方塊）
- 道具：`stoneBlock`（石頭方塊 64×64）、`log`（木頭 96×32）、`stump`（樹墩 48×50）、`grassBlock`，都有 `collider.kind:'solid'`。在測試場景擺：單顆方塊、2–3 級階梯（stoneBlock 依序疊高 1、2 塊）、一根木頭、一個樹墩、一段「石頭方塊＋木頭」的小跳台。總高不要超過約 130 單位（普通跳最高約 130 單位；**蓄力跳**可到約 2 倍，才上得去更高的）。
- **solid 規則**：
  1. 從上方落下，腳底穿過 `box` 上緣（`box.y`）→ 站上：腳底吸附上緣、垂直速度歸零、落地動作規則同地面（移動中不播 `land`）；站在上面可左右走、跑、蹲、再跳。
  2. 水平移動時碰到 solid 側面（腳底低於上緣 ≥ 6 單位）→ 被擋住（不穿越、不絆倒）。腳底只低於上緣 < 6 單位的**小台階**自動踏上去（木頭 26 單位高時，需要跳；不做自動踏上）。
  3. 從下方跳起頭碰到底面→彈回（垂直速度歸零往下）；`giftBlock` 從下方頂到仍照原規則切「被撞擊」狀態。
  4. 走出平台邊緣→進入下落（`fall` 動作），落地規則不變。
  5. 站在 solid 上時，蹲下、蓄力、彈簧、坐下都正常運作。
  6. 角色的陰影（`#gshadow`）要貼在**腳下的支撐面**（地面或 solid 上緣），不是舞台地面。
- 圖層：solid 與 hazard 道具畫在角色**後方**一層（與地面同一層級，`z-index` 低於角色），僅 `front:true` 的裝飾道具畫前面。
- 全部障礙物放在同一份場景資料（`obstacles: [{id,x,state?}]`，x 為舞台寬比例），之後新增只改資料；場景捲動時障礙物跟著**地面**（視差 1）移動。

## 4. 蓄力改為發光
- 取消「蓄力圖示」（任何 icon／環／文字）。改用角色內建光暈：`GameArt.setCharge(svgEl, on, full)`。
  - 按住 ↓ 在地面且 ≥ 0.35 秒：`setCharge(svg, true, false)`（柔和脈動光暈＋上升光點，開始蓄力的視覺回饋）。
  - ≥ 1 秒（已可蓄力跳）：`setCharge(svg, true, true)`（更亮、脈動更快）。
  - 放開 ↓ 且超過 300ms 寬限、起跳、被絆倒、離地：`setCharge(svg, false)`。
- 角色重畫（切視角、換造型）後要重新套用目前蓄力狀態；`prefers-reduced-motion` 時 CSS 已自動變靜態光暈（不脈動、不飄光點），不用額外處理。
- 光暈是角色 SVG 的一部分，不需要額外 DOM；`exportSVG` 拍照預設不含（光暈預設隱藏）。
