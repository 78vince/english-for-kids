# Handoff：角色工作室第二輪修改（6 項）

*撰寫：2026-10-08（內容端）｜執行對象：`/Users/admin/VK Agent/English for Kids LetsGo/`（App 端）｜只改新專案｜依據：使用者對已實作工作室的截圖回饋*
*前置：先把 `assets/game-tokens/` 更新到最新（`game-tokens.json`、`game-character.js` 有改動：新增 `pantsColor: 'match'`）。*

## 1. 褲子顏色可「同衣服色」
- token 已支援：`look.pantsColor = 'match'` → 褲子（含連身褲／洋裝的下半部）與 `outfitColor` 同色。選項清單 `options.pantsColor` 的第一項即 `match`。
- UI：服裝分頁的褲色區，色票列之外多一顆「**同衣服**」按鈕（不是色相，不要用 `T.color.hue['match']`，會報錯）；選取時色票全部取消選取。新建角色預設仍維持原預設褲色。
- 舊存檔的 `pantsColor` 不變，無需遷移。

## 2. 角色可重新命名
- 角色槽卡片與頂部列的名稱都可點擊編輯（行內輸入，Enter／失焦儲存，Esc 取消）；1–12 字，中英文數字，禁空白與純符號，不合規顯示簡短提示（`.g-bubble`）並保留原名。
- 寫入該槽 `name`、`updatedAt`，走既有 800ms 自動存檔與同步；名稱變更不進復原／重做堆疊。

## 3. 第 2、3 個角色可刪除
- 第 1 個角色不可刪（至少保留一個）；第 2、3 個槽卡片出現刪除鈕（`trash` icon，≥ 44px，放卡片右上角，避免誤觸）。
- 點擊 → 二次確認（圖示＋兩顆大按鈕「刪除」「取消」，文字簡短，顯示該角色頭像與名稱）。刪除後該槽回到「＋新角色」空位；若刪的是使用中角色，自動切到第 1 個。
- 已拍的照片不隨角色刪除（相簿照片的 `slot` 欄位保留但不再顯示角色名時以「已刪除的角色」帶過）。徽章「造型師」以**累計紀錄**判定，刪除不會讓已得徽章消失（`stats` 另外記錄 `slotsEverSaved` 的不同 look 數）。

## 4. 選單縮圖不要疊加其他分類的配件
截圖問題：配件分頁每張縮圖都帶著目前選中的蝴蝶結、星星髮夾、背包、手持物…，看不出這個款式本身。
規則（縮圖專用 look）：
- 先複製使用者目前的 `look`，再依所在分頁**清掉選配項目**：
  - 配件分頁：`accessories = [該款]`、`held = 'none'`。
  - 手持物分頁：`held = 該款`、`accessories = []`。
  - 身體／頭髮／臉／服裝分頁：`accessories = []`、`held = 'none'`（核心外觀如膚色、髮型、眼口、服裝仍沿用使用者目前的，才看得出差異）。
- 縮圖的「已選」外框仍依**實際 look** 判斷；舞台上的角色不受影響，仍顯示全部配件。
- 縮圖統一用正面、`pose: null`（靜止）。

## 5. 踩彈簧會跳得更高
- 角色**下落**時腳底接觸彈簧道具（`spring`）頂部 → 彈簧切到下壓狀態（`GameArt.propStates('spring')`，播放壓縮→彈起）→ 角色以**普通跳躍高度的 1.8 倍**彈起：由 `h = v²/2g` 得初速 `v = v0 × √1.8 ≈ 1.34 × v0`（重力不變）。
- 站在地面、走過彈簧不觸發；從下方頂到不觸發；觸發時浮出「+」或 `sparkle` 提示即可（沿用 `.g-float`）。
- 彈起期間仍可左右移動；空中水平速度規則不變（由起跳／彈起當下是否按著 B 決定）。落地規則不變。
- 同一個彈簧連續踩可重複觸發；不加冷卻。

## 6. 蹲下蓄力 → 兩倍高度跳
- 在地面按住 ↓ 超過 **1 秒**進入「蓄力」：角色維持蹲下姿勢，並有明確回饋（建議：身體輕微脈動縮放 ±3%、腳邊出現小粒子／`sparkle` 環；蓄力滿的瞬間播一次輕音效與震動，若裝置支援）。1 秒前不顯示。
- 蓄力中按 A → 起跳**高度為普通跳的 2 倍**：`v = v0 × √2 ≈ 1.414 × v0`。蓄力狀態在**放開 ↓ 後 300ms 內**仍有效（避免手指換鍵就失去蓄力），超過即取消；放開 ↓ 沒跳會自然站起，無懲罰。
- 蓄力跳與彈簧不疊加：同時成立取較大者（彈簧 1.8× 與蓄力 2×，取 2×）。蓄力跳後立即清除蓄力狀態。
- 蹲下期間仍**不能前進**（既有規則）；蓄力跳起後空中可水平移動，規則不變。
- 工作室頂部提示氣泡新增一次性提示：「按住 ↓ 一下下，再按 A，跳更高！」第一次蓄力成功後不再出現。
- 新增 `stats.posesTried`（陣列，記錄在工作室「動作」分頁表演過的 pose id）給徽章 CS-07「動作達人」使用（條件：`GameArt.poses` 全部都出現；見 `docs/image-prompt-letsgo-character-badges.md`）。
- 舞台高度限制：蓄力跳最高約舞台高 52%，要確認不遮住 HUD；必要時把角色位置參數 `feetY` 維持 0.88、不要被遮。
