# Handoff：工作室編輯造型時維持目前視角

*撰寫：2026-10-12（內容端，依使用者回饋）｜執行對象：`English for Kids LetsGo/app/src/games/characterStudio.ts`（及 `StageController` 的視角處理）｜只改新專案｜token 端已無需修改（另有 v1.0.2 刺蝟頭尖刺改短小）*

## 需求（使用者原話）
「當我設定成側面的時候，選擇任一配件如髮型，此時人物應該繼續維持側面並且更新選擇的配件。」

## 現況
§14.2：「編輯造型時轉回正面，一移動自動側面」——選款式時一律把舞台角色轉回正面；使用者在右側視角鈕選了「側」或「背」，一點髮型、服裝或配件就跳回正面，無法檢查側面／背面的造型。

## 修改
1. **選任何造型選項**（身體、頭髮、臉、服裝、配件、手持物、預設角色、隨機、還原、復原／重做）時，**不要改視角**：使用者目前是正面／側面／背面，套用後就維持哪一個，只重畫角色的 look。側面時維持目前 `facing`（左右鏡像）。
2. 視角只由這些操作改變：右上角「正／側／背」鈕、玩家開始移動（左右鍵，自動側面——維持現有行為）。「隨機」「預設角色」也不重置視角。
3. 若原本「選款式轉正面」是為了讓縮圖或舞台看得到款式，可以改成：**縮圖維持正面（`thumbLook()` 不變）**，舞台角色維持使用者選的視角。
4. 視角鈕的「正／側／背」選中狀態要和實際視角一致（移動後自動轉側面時，鈕也要跟著亮「側」）。
5. 拍照、相簿、頭像不受影響（頭像一律正面）。

## 驗收
- 在「側」視角下點髮型（含刺蝟頭、旁分劉海）、服裝、配件、手持物、臉型、眉毛：角色維持側面並立即更新；「背」同理；「正」維持正面。
- 隨機、預設角色、還原、復原／重做後視角不變。
- 側面開始移動後視角鈕亮「側」；面向左時（`facing:'left'`）更新造型後仍朝左。
- 工作室與賽跑回歸（賽跑角色一律由舞台決定視角，不受工作室設定影響）。
