# 「每天玩一點，英語變好玩」風格改版計劃

本方案是另一個風格提案（與「英語島 EnglishIsle」島嶼主題方案為互斥的替代選項，非疊加），基於 `assets/design-tokens/design-tokens.css` / `.json` 原稿與現行 `app/demo-standalone.html` 頁面結構提出。對應的 token 提案檔案：`assets/design-tokens/design-tokens.v2-daily-play.css` / `.json`（獨立版本，未覆蓋原稿，確認採用後再合併）。

---

## 1. 品牌與風格定位

- **平台名稱直接採用口號全文：「每天玩一點，英語變好玩」**，不另外簡稱或造字標。首頁／登入頁的品牌區直接以這句話作為主標題呈現。
- 風格方向：**簡單大器**——不做主題世界觀包裝，用放大字級、乾淨留白、清楚的功能動線來建立信任感；核心訴求是「養成每天玩一點的習慣」。
- 與「英語島」方案的差異：這個方案**不更動品牌色相**，只調整中性色、字級與版面結構，實作風險比重新調色更低；「英語島」方案走情境包裝，這個方案走機能與習慣養成。

---

## 2. Design Token 改版重點

完整數值見 `design-tokens.v2-daily-play.css` / `.json`，重點說明如下：

| 項目 | 改版方向 | 原因 |
|---|---|---|
| 品牌色（primary／secondary／accent） | **維持原稿不變** | 降低實作與品牌識別風險，改版聚焦版面與字級 |
| 字級（`--text-*`） | 全面放大約 10–20%（例：body 16px→18px，h1 32px→36px，display 40px→48px） | 對應「較大的字級」需求，提升可讀性與大器感 |
| 中性背景／邊框 | `--color-bg` 由淡紫 `#F7F2F8` 改中性灰藍 `#F4F6F9`；`--color-border` 同步改灰藍 | 降低粉嫩感，讓畫面更沉穩乾淨 |
| 圓角／間距／陰影 | 沿用原稿數值 | 現有數值已符合「簡單」調性，不需更動 |
| 新增：功能列 token | `--nav-height`、`--nav-item-active-bg` 等 | 支援下方第 3 節的固定功能列 |
| 新增：徽章分級色 | `--color-tier-bronze/silver/gold` 及對應底色、`--color-tier-locked` | 支援第 4 節成就徽章系統 |

## 3. 明確的功能列（新增元件）

**現況**：`demo-standalone.html` 目前沒有全站固定導覽，僅有畫面右上角的「返回」按鈕（`.back-btn`），所有畫面在同一個 720px 容器內依序切換。

**改版**：新增一個固定功能列，四個功能項目：

1. **首頁**（原「選主題」畫面，`.menu-list`）
2. **挑戰紀錄**（原統計頁 `.stats-summary` / `.stats-card`）
3. **成就徽章**（原 `.badge-grid`，改版見第 4 節）
4. **我的**（原登入/切換玩家頁）

視覺規則：

- 使用 icon＋文字標籤，選中項目用 `--nav-item-active-bg`（primary-700）底色＋白字凸顯，不用小圓點或底線這類較「可愛」的指示方式，維持大器感。
- 版位建議：桌面／平板置頂（sticky top，位於品牌區下方）；手機寬度置底（bottom tab bar），符合行動裝置慣用手勢熱區。
- 功能列本身固定高度 `--nav-height: 64px`，字級沿用放大後的 `--text-body`，確保觸控區與可讀性足夠。

## 4. 成就徽章系統設計

**現況**：僅有 6 個徽章（跨出第一步、主題全通關、全主題制霸、單字小達人、單字大師、神射手），以單一列表平鋪呈現，沒有分類與分級，也對應 `HANDOFF.md` 中列為 Phase 2 待辦的「積分/連續天數/徽章/報告」。

**改版：分 4 個類別，每個類別 3 個等級（銅／銀／金）**，共 12 個徽章：

| 類別 | 銅 | 銀 | 金 |
|---|---|---|---|
| 學習里程碑（累計學會單字數） | 跨出第一步（完成第一次配對） | 單字小達人（累計 50 個單字） | 單字大師（累計 150 個單字） |
| 精準度（單一關卡正確率） | 小神射手（正確率 80%+） | 神射手（正確率 90%+） | 完美射手（正確率 100%） |
| 主題征服（完成主題全部題型） | 主題全通關（完成 1 個主題） | 三主題達人（完成 3 個主題） | 全主題制霸（完成所有已上架主題） |
| **每日習慣**（連續遊玩天數，呼應「每天玩一點」） | 三日不間斷（連續 3 天） | 一週好習慣（連續 7 天） | 月度習慣王（連續 30 天） |

> 「每日習慣」為新增類別，直接對應平台口號，是這個方案與「英語島」方案在徽章設計上最大的差異——用連續登入天數強化「每天玩一點」的核心價值主張，而非只獎勵單次成績。

**視覺設計**：

- 每個徽章卡片用對應等級色（`--color-tier-bronze/silver/gold`）做外框與底色，未解鎖沿用 `--color-tier-locked` 灰階剪影。
- 成就徽章頁改為「分類分組」版面：4 個類別各一列，每列橫向排列銅／銀／金三張卡，未達成的等級用剪影＋進度條顯示「還差多少解鎖」（例如「還差 12 個單字解鎖銀牌」），取代現行純平鋪 `.badge-grid`。
- 圖示可先用現有 emoji 佔位（🥉🥈🥇／⭐️🎯🏆／🗺️🔥），之後再視需要委託設計正式圖示。

## 6. 給執行 section 的實作注意事項

1. `design-tokens.v2-daily-play.css` / `.json` 為獨立提案檔案，**未覆蓋**原始 `design-tokens.css` / `.json`；確認採用此方向後，再將差異值合併回主檔案。
2. 字級全面放大後，需重新檢查既有卡片／按鈕內距是否足夠，避免文字被擠壓或換行跑版（尤其 `.menu-item-label`、`.stats-card-title` 這類原本用 `--text-body-lg` 的元件）。
3. 新增功能列為**新元件**，需另外刻版面與行為（含 RWD：桌面 sticky top／手機 bottom tab bar），不是既有元件的樣式覆寫。
4. 徽章解鎖邏輯（累計單字量、連續天數、正確率、主題通關）需要 `app/src/progress.ts` 擴充追蹤欄位（目前僅記錄「使用者＋主題＋題型」的次數與最佳正確率，尚未記錄連續登入天數），屬於 Phase 2 範圍，建議與內容/邏輯開發排在一起規劃，不只是視覺改版。
