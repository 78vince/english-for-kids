# 成就徽章列表

本文件是成就徽章系統的第一版設計清單，供後續設計徽章樣式、製作成就徽章頁面使用。

## 徽章的兩種類型

| 類型 | 說明 | 範例 |
|---|---|---|
| **一次性** | 終身只能取得一次，達成後永久保留，通常是累計數值達到門檻（如單字量、題數）| 單字小達人 100 |
| **累積次數（重複觸發）** | 條件每次達成都會再取得一次，徽章下方顯示「已達成 N 次」。其中「連續天數／連續答對」這類徽章有一個計數器：每符合條件的一天（或一題）+1，**計數器一滿門檻，立刻算達成一次、累計次數 +1，並把計數器歸零重新從 0 開始下一輪**——所以只要持續不中斷，每滿一次門檻就會再拿到一次；但只要中途中斷一次（缺一天沒玩、或答錯一題），計數器一樣會歸零，只是這種情況**不會**增加累計次數。「完美關卡」這類非連續型的重複徽章則單純每次事件各自獨立判定，沒有連續與中斷的概念 | 三日不間斷、連勝十題、完美關卡 |

目前共設計 **44** 個徽章，分成 10 大類。

## 徽章代號命名規則

代號格式：`<2 碼分類字母>-<該分類內流水號 2 碼>`，例如 `VM-01`。設計時把握三個原則：

- **簡單**：固定 5 碼格式（2 碼字母＋連字號＋2 碼數字），一眼就能看出結構，不需要額外說明就能認出「這是一個徽章代號」。
- **易辨識**：字母直接對應分類的英文縮寫，看到代號前兩碼就知道屬於哪一大類，不用查表也能大致猜到。
- **可擴充**：同一分類要新增徽章，直接接續流水號（例如 VM 之後加 VM-06）；要開全新分類，指派一組沒用過的字母即可，兩種情況都不會動到既有徽章的代號，舊代號永久有效、不會被重新編排。

## 設計備註

1. **關於「深夜」類型徽章**：原始構想中曾考慮加入類似「深夜貓頭鷹」（晚間時段學習給獎勵）的趣味徽章，但這類設計等於變相鼓勵孩子熬夜使用 3C 產品，跟兒童使用時間健康原則衝突，因此本版本刻意只保留正向時段（早起、假日）的作息類徽章，不設置任何鼓勵深夜/熬夜使用的徽章。

2. **生日徽章（待評估）**：原本想加入「生日快樂」類徽章（使用者生日當天登入即可取得），但目前的使用者資料模型（見 `docs/content-plan.md`，原檔名 `content-plan-gept-kids.md`，與既有使用者欄位規劃）尚未包含生日欄位，需要先確認是否要新增此個資欄位、以及兒童個資蒐集的必要性與家長同意機制後，才適合實作，故本版本未列入正式徽章清單。

3. **題型精通徽章目前每種題型只設 2 階**（新手／大師），如果之後覺得進度感不夠，可以參考單字里程碑的做法擴充成 3-4 階，資料結構（`tier_group` / `tier_level`）已經支援直接擴充，不需改架構。

4. **口說題型（Phase 4，延後開發）目前未設計對應徽章**，待語音辨識功能實際開發時，再依相同資料結構（`content/schema/badge.schema.json`）新增 `speaking` 分類即可，不影響現有徽章。

5. 所有徽章的 `icon_placeholder` 欄位目前皆為空值，待徽章樣式設計定案後，填入對應圖檔路徑（建議慣例：`assets/badges/{badge_id}.svg`）。
