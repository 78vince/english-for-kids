# Handoff：賽跑手機橫式版面重新規劃（App 端）— game-tokens v1.8.0

*撰寫：2026-10-13（內容端，依使用者在 iPhone 橫式的截圖回饋）｜執行對象：App 端 `app/`（賽跑頁 `race.css`／`race.ts`、虛擬按鍵 `virtualPad.ts`、完成對話框）｜規格數值在 `assets/game-tokens/game-tokens.json` 的 `layout.landscapePhone`*
*對照圖：`handoff-prompt-letsgo-race-landscape.mockup.png`（上：目前；下：新版 852×393）*

## 問題（iPhone 橫式，約 852×393）
1. 虛擬方向鍵蓋在遊戲畫面上，遮住大部分賽道。
2. 上一頁、頭像、名稱、音量、代幣在畫面上方佔一整排，擠壓遊戲畫面高度。
3. 過關對話框太高，一個畫面看不完（角色圖被切掉、按鈕被擠到底）。

## 規劃
### 1. 三欄版面（左欄｜遊戲畫面｜右欄）
- 啟用條件：`(orientation: landscape) and (max-height: 500px)`；直式與平板（高度 > 500）維持原樣。
- 外層 `height: 100dvh`、不捲動，左右 padding 加 `env(safe-area-inset-left/right)`，上下加 `env(safe-area-inset-top/bottom)`。
- 遊戲畫面維持 **16:9**、置中，大小由「寬度」決定：`寬 = 視窗寬 − 兩側 safe-area − 左欄 144 − 右欄 96`。**不要裁切賽道視野**（視野比例變了會影響公平與難度）。
- 這代表畫面本身大小跟現在差不多（852×393：約 518×291，現在約 539×303），差別是**不再被任何東西蓋住**；垂直方向多出的空間改放資訊列（見下）。

### 2. 左欄（寬 144）
- 上：返回鈕（44）、頭像（36）＋名稱（最多 6 字、超過省略、不顯示「稱號」那行）。
- 下：← （56）、→ （72，做大，連點最常用）；兩鍵並排，間距 8。**↑、↓ 在賽跑不作用（蹲滑已移除），橫式不顯示。**（直式與平板若仍顯示請另案；建議也拿掉 ↑↓。）

### 3. 右欄（寬 96）
- 上：代幣（精簡：圖示＋數字）、音量、暫停（暫停從畫面右上角移到這裡）。
- 下：A 跳（72）在上、B 道具（56）在下，沿拇指弧線排列，不互相重疊。
- 所有按鈕觸控區 ≥ 56px（連點用的 → 72）；維持現有 `touch-action: manipulation` 與防縮放（見 `handoff-prompt-letsgo-pad-no-zoom.md`）。

### 4. 畫面上方細列（高 32）
- 計時與進度條（旗子、頭像）改放在遊戲畫面**上方**的細長資訊列，不再覆蓋畫面。

### 5. 過關對話框（橫式雙欄）
- `max-height: calc(100dvh - 16px)`，內容不夠高時內部才捲動（最後保險，不依賴它）。
- 左欄：角色與烏龜圖（最高 38dvh）、「第 N 名！」、星星。
- 右欄：統計改成精簡 chips（時間（含目標）、贏烏龜 N 步、撿到道具 N 個、撞到 N 次），下面是三個按鈕（回選單／再賽一次（5）／下一位對手），按鈕可橫排縮小。
- 直式維持現有單欄。

### 6. 其他
- 倒數、暫停選單、訊息提示若有固定在畫面中央，改成置中於遊戲畫面（不是整個視窗）。
- 先在 667×375、852×393、932×430 三種尺寸驗證；有安全區（Dynamic Island 那側）時按鈕不可被擋。
- 想要更大的畫面，需放寬 16:9（例如改 3:2）。這會改變視野，請先跟內容端確認再做。

## 驗收
- iPhone 橫式：方向鍵、A／B、HUD 都不遮住遊戲畫面；所有按鈕單手拇指可按。
- 過關對話框在 667×375 也能一次看完（角色、名次、星星、統計、三個按鈕）。
- 直式與 iPad 版面不變；沒有水平／垂直捲動；連點 → 不會放大畫面。
